# Icônes de la page d'accueil

Dépose ici un fichier **PNG** par page, nommé exactement comme dans la
colonne « Fichier ». Tant qu'un fichier manque, la page d'accueil affiche
l'emoji de secours : tu peux donc les ajouter au fur et à mesure, sans
toucher au code.

Conseils : image carrée, fond transparent, 128×128 px ou plus (elle est
affichée en 56×56, la taille supplémentaire sert aux écrans haute définition).

Pour changer un nom, une description ou l'emoji de secours, ou ajouter une
page : `src/lib/navigation.ts`.
